# SoundMaster

A real, native Windows program that manages your actual audio. One exe, no install, no
runtimes to download, no browser anywhere — built with the C# compiler that ships inside
Windows. Runs on Windows 10 (incl. IoT LTSC).

## Run it

Double-click **`SoundMaster.exe`**. That's the whole install.

## What it does — to real Windows audio

- **Playback / Recording views** — every endpoint on the system (active, disabled, unplugged).
  - **Set default** — changes the actual Windows default device (what Wave Link can't do for
    you on Windows 10). **Comm** sets the communications-role default (Discord and calls).
  - Per-device **volume + mute** with **live meters**.
  - **Disable / Enable** — same result as disabling in the old Sound control panel, so devices
    you never use stop cluttering every app's device picker. Needs one admin (UAC) approval
    per toggle.
- **Apps view** — every app playing or recording audio: per-app volume and mute, including
  which device each stream uses, playback *and* microphone sessions.
- **Audio flow** — the live signal-path diagram, drawn from your *real* topology:
  microphones → apps → outputs. Cyan wires = app capturing an input, magenta = app playing to
  an output, dashed = muted, faint = idle. Traveling dots ride active wires and glow with
  actual signal level. Click any card to trace its path; Esc or click empty space to clear.
  Blue dot = the current default device.
- Keyboard: **Ctrl+1..4** switches views. Everything applies to Windows immediately.

## Rebuild from source

```
native\build.bat
```

Uses `%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe` — present on every Windows
with .NET Framework 4.x (all of them). Source in `native\src\`.

### Package for testers

```
powershell -ExecutionPolicy Bypass -File native\make-dist.ps1
```

Builds, then writes `dist\SoundMaster-<version>.zip` (exe + tester README from
`native\TESTERS.txt`). Version lives in `native\src\AssemblyInfo.cs`. App icon is
`native\app.ico`, regenerated by `native\make-icon.ps1`.

`SoundMaster.exe --selftest` prints a full read-only diagnostic of the audio system.

## Notes

- Default-device switching uses the same internal interface the Sound control panel uses
  (`IPolicyConfig`; this machine exposes the Vista variant — handled automatically).
- Not affiliated with Elgato. The Audio Flow view is inspired by Wave Link 3.3's diagram,
  rebuilt from scratch for real Windows topology.
- `web/`-era prototype files (index.html, js/, css/, server.ps1) are the earlier browser demo;
  the exe replaces them. Keep or delete as you like.
